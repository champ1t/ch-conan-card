# CH.จุ่มการ์ดโคนัน 

เว็บแอปร้านจุ่มการ์ด Detective Conan TCG & การ์ดสะสม พร้อมระบบจำลองการเปิดซองการ์ดสุด Luxury เอฟเฟกต์โฮโลแกรม แสง สี เสียง และระบบการันตี (Pity System)

## ฟีเจอร์เด่น
- **ระบบเปิดซองการ์ด (Pack Opening Simulator)**: อนิเมชั่นฉีกซองและเปิดการ์ดสุดลื่นไหล พร้อมเอฟเฟกต์ตามระดับความแรร์
- **Luxury Holographic Card Effects**: เอฟเฟกต์โฮโลแกรม ฟอยล์สะท้อนแสง และ 3D Card Tilt
- **Hot Cards Popup & Guarantee System**: หน้าต่างดูการ์ดไฮไลท์ประจำชุด และระบบการันตีความแรร์
- **ระบบจัดการสินค้าและคำสั่งซื้อ**: รองรับการสั่งซื้อผ่านหน้าเว็บและเชื่อมต่อฐานข้อมูล Firebase Firestore
- **Responsive Design**: แสดงผลสวยงามทั้งบนมือถือ แท็บเล็ต และคอมพิวเตอร์

## สแต็กเทคโนโลยี
- **Frontend**: HTML5, Vanilla CSS3 (Custom Luxury Design System), Modern JavaScript
- **Backend / Database**: Firebase Hosting & Firebase Cloud Firestore
